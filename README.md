# Criando-um-Plano-de-Aula-Interativo-e-Personalizado-com-Ecossistema-IA
Planejamento de aula de Ciências sobre cadeia alimentar para o 8º ano do Ensino Fundamental, com duração de 50 minutos. A aula utiliza slides e Inteligência Artificial como apoio didático, integrando explicação teórica, atividade prática em grupo e socialização dos aprendizados, conforme a BNCC.
